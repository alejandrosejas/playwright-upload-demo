# playwright-upload-demo

Simple Playwright project that shows how to upload files using steps and manipulating the DOM.

## Prerequisites

- Node.js installed
- npm or yarn package manager

## Installation

1. Clone the repository:
```bash
git clone https://github.com/alejandrosejas/playwright-upload-demo.git
```

2. Install dependencies:
```bash
npm install
```

## Running Tests

To run the tests:
```bash
npx playwright test
```

To run tests with UI:
```bash
npx playwright test --ui
```

To view the test report:
```bash
npx playwright show-report
```

## Test Description

The project demonstrates file upload functionality using Playwright:
- Navigates to a test page
- Uploads a file using input element
- Verifies successful upload message
